**MVP, 6 месяцев:** клиент подаёт заявку онлайн, бэк-офис обрабатывает её в АБС. Оба кол-центра получают общие ставки.

**Цель, 12 месяцев:** депозиты и накопительные счета открываются без бэк-офиса, в отделении работает только фронт-офис.

Новый клиент с сайта проходит идентификацию в отделении. Кредитование в MVP не входит.
