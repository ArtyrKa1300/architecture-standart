# Задачи и RoadMap

Сроки предварительные, месяцы считаются от старта проекта. Те же номера задач показаны на [RoadMap](roadmap.drawio) ([SVG](roadmap.svg)).

| ID | Система / команда | Задача | Месяцы | Зависимости |
|---|---|---|---|---|
| T01 | Все команды, бизнес и ИБ | Согласовать требования, API, события, файловый обмен и критерии приёмки. | 1 | — |
| T02 | IT / DBA | Подготовить инфраструктуру, БД, Kafka и резервирование. | 1–3 | T01 |
| T03 | АБС / бэк-офисы | Создать справочник ставок с ролями и перенести данные из Excel. | 2–3 | T01 |
| T04 | Команда АБС | Реализовать адаптер Kafka, доставку без потерь и защиту от дублей. | 2–4 | T01; завершить после T02/T03 |
| T05 | Команда банка | Создать каталог, заявки и статусы в сервисе депозитов. | 3–4 | T02–T04; разработка по согласованным контрактам |
| T06 | Команда банка / IT | Сделать СМС-подтверждение и уведомления через шлюз. | 2–4 | T01/T02 |
| T07 | Интернет-банк | Добавить экраны каталога, заявки и статусов, интеграцию авторизации. | 4–5 | T05/T06 |
| T08 | Сайт | Добавить каталог и форму обращения. | 4–5 | T05 |
| T09 | АБС | Добавить ручную обработку онлайн-заявок и открытие депозита. | 3–5 | T03/T04 |
| T10 | Кол-центр банка | Принимать обращения с сайта через Kafka. | 4–5 | T05 |
| T11 | Кол-центр банка | Показывать общие ставки через API. | 4–5 | T05 |
| T12 | IT / ИБ | Развернуть SFTP и проверить доступ партнёра. | 2–3 | T01/T02 |
| T13 | Сервис депозитов | Сделать API ставок, выгрузку CSV, контроль ACK и повторов. | 4–5 | T05/T12 |
| T14 | Партнёрский кол-центр | Реализовать импорт файлов, ACK и экран ставок. | 3–5 | Контракт T01, стенд T12; проверить вместе с T13 |
| T15 | Все команды / QA | Проверить интеграции, нагрузку, отказы, права и повторы. | 5–6 | Готовые части T04–T14 |
| T16 | Бизнес / эксплуатация | Провести пилот, обучение и запуск MVP. | 6 | T15 |
| T17 | АБС / бэк-офисы | Автоматизировать согласованные правила ставок и риска. | 7–8 | T16 |
| T18 | АБС / сервис депозитов | Автоматизировать открытие после подтверждения клиента. | 9–11 | T17 |
| T19 | АБС / фронт-офис | Использовать автоматическое открытие в отделении. | 9–11 | T17; проверить совместно с T18 |
| T20 | Все команды / QA | Проверить автоматическое открытие, нагрузку и восстановление. | 10–12 | Готовые части T18/T19 |
| T21 | Бизнес / все команды | Запустить автоматический процесс и оценить результат. | 12 | T20 |

**Месяц 6:** заявки с сайта и интернет-банка, ручная обработка в АБС, актуальные ставки в обоих кол-центрах.

**Месяц 12:** штатные депозиты и накопительные счета открываются без бэк-офиса; в отделении участвует только фронт-офис.

Новые требования согласуются с бизнесом и затронутыми командами, после чего обновляются ADR и RoadMap. T10 и T11 выполняет одна небольшая команда подрядчика, её загрузку нужно планировать совместно.
